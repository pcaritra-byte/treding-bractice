# ChartPilot — Trading Dashboard Starter (বাংলা নির্দেশিকাসহ)

বাংলা নির্দেশনা সহ একটি পূর্ণাঙ্গ **Next.js 15 + TypeScript** charting dashboard starter, যা **Lightweight Charts** দ্বারা চালিত। এতে রয়েছে ট্রেডিংভিউ-এর মতো প্রফেশনাল মাল্টি-চার্ট গ্রিড, ভিজিবল রেঞ্জ ভলিউম প্রোফাইল (VRVP), অ্যালগরিদমিক বাই/সেল সিগন্যাল, বার রিপ্লে মোড, পেপার ট্রেডিং সিমুলেটর এবং রিয়েলটাইম প্রাইস অ্যালার্ট সিস্টেম।

---

## ⚡ আগে যা লাগবে
- **Node.js 20.9+** (Next.js 15-এর জন্য)
- **npm** অথবা **pnpm**
- **VS Code** বা যেকোনো আধুনিক কোড এডিটর

---

## 🚀 চালানোর ধাপ (How to Run)
1. টার্মিনাল খুলুন এই প্রজেক্ট ফোল্ডারে: `d:\New folder (2)`
2. ডিপেনডেন্সি ইনস্টল করতে চালান:
   ```bash
   npm install
   ```
3. লোকাল ডেভেলপমেন্ট সার্ভার চালু করুন:
   ```bash
   npm run dev
   ```
4. ব্রাউজারে খুলুন:
   ```text
   http://localhost:3000
   ```

## 🌟 বর্তমান সিস্টেমে যা যা রয়েছে

### ১. লাইটওয়েট চার্টিং ইঞ্জিন (Lightweight Charts)
- **ক্যান্ডেলস্টিক চার্ট**: স্মুথ ইন্টারঅ্যাক্টিভ জুম, প্যান ও ক্রসহেয়ার।
- **মুভিং এভারেজ রিবন**: EMA 20 (Cyan), EMA 50 (Gold), EMA 200 (Purple)।
- **বলিঙ্গার ব্যান্ডস (Bollinger Bands)**: ২০ পিরিয়ড এবং ২ স্ট্যান্ডার্ড ডেভিয়েশন ব্যান্ড।
- **মাল্টিপল টাইমফ্রেম**: `1m`, `5m`, `15m`, `1h`, `4h`, `1D`, `1W` টাইমফ্রেম সুইচিং।

### ২. ভিজিবল রেঞ্জ ভলিউম প্রোফাইল (Visible Range Volume Profile - VRVP)
- স্ক্রিনশট ১ এবং ৩-এর অনুরূপ চার্টের ডান পাশে অনুভূমিক ভলিউম ক্লাস্টার।
- **POC (Point of Control)**: সর্বোচ্চ ভলিউম ট্রেড হওয়া প্রাইজ লেভেল চিহ্নিতকরণ।
- **VAH (Value Area High)** ও **VAL (Value Area Low)**: ৭০% ভ্যালু এরিয়া ক্যালকুলেশন।
- বায়ার ও সেলার ডেল্টা রঙ (ব্লু/অরেঞ্জ স্প্লিট)।

### ৩. মাল্টি-চার্ট গ্রিড লেআউট (TradingView Tier System)
- **১টি চার্ট**: ফুলস্ক্রিন ফোকাসড ভিউ।
- **২টি চার্ট স্প্লিট**: সাইড-বাই-সাইড অথবা উপরে-নিচে বিভক্ত ভিউ।
- **৪টি চার্ট গ্রিড**: ২x২ কোয়াড গ্রিড (স্ক্রিনশট ২-এর অনুরূপ - একাধিক অ্যাসেট বা একাধিক টাইমফ্রেম পর্যবেক্ষণ করার জন্য)।

### ৪. টেকনিক্যাল ইনডিকেটর সাব-পেন (RSI ও MACD)
- **RSI (14)**: ৩০ ওভারসোল্ড এবং ৭০ ওভারবট লেভেল ব্যান্ড সহ।
- **MACD (12, 26, 9)**: ফাস্ট লাইন, সিগন্যাল লাইন এবং পজিটিভ/নেগেটিভ হিস্টোগ্রাম।

### ৫. অ্যালগরিদমিক বাই/সেল সিগন্যাল (Rule-Based Demo Signals)
- গোল্ডেন ক্রস ও ডেথ ক্রস ডিটেকশন (EMA 20 crossing EMA 50)।
- RSI ওভারসোল্ড রিকভারি ও ওভারবট রিজেকশন।
- চার্টের ক্যান্ডেল বারে সরাসরি অ্যারো মার্কার (যেমন `BUY @ 67,420`, `SELL @ 68,150`)।
- সিগন্যাল ফিড কার্ডে এন্ট্রি, স্টপ লস (SL), টার্গেট (TP) এবং কনফিডেন্স স্কোর সহ 'Simulate' বাটন।

### ৬. পেপার ট্রেডিং সিমুলেটর (Paper Trading System)
- **$100,000 নগদ ব্যালেন্স** দিয়ে ঝুঁকিহীন সিমুলেশন।
- **মার্কেট ও লিমিট অর্ডার**: Buy / Long এবং Sell / Short সাপোর্ট।
- **পজিশন সাইজিং**: ১০%, ২৫%, ৫০%, ১০০% কুইক ব্যালেন্স বাটন।
- **স্টপ লস (SL) ও টেক প্রফিট (TP)** ইনপুট।
- **ওপেন পজিশন টেবিল**: লাইভ মার্ক প্রাইস, অনাদায়ী লাভ/ক্ষতি (Unrealized P&L $ ও %) এবং 'Close Position' বাটন।
- **ট্রেড হিস্ট্রি ও উইন রেট**: বন্ধ করা ট্রেডের রেকর্ড ও মোট অর্জিত লাভ/ক্ষতি।

### ৭. প্রাইস অ্যালার্ট সিস্টেম (Price Alerts)
- ক্রস অ্যাবাভ (Cross Above) বা ক্রস বিলো (Cross Below) অ্যালার্ট তৈরি।
- লাইভ প্রাইস লেভেল টাচ করলে **ওয়েব অডিও কাস্টম চাইম** এবং ফ্লোটিং টোস্ট নোটিফিকেশন।
- `localStorage`-এ সেভ থাকে, ফলে রিলোড দিলেও অ্যালার্ট বজায় থাকে।

### ৮. বার রিপ্লে মোড (Bar Replay)
- অতীতে ফিরে গিয়ে ক্যান্ডেল বাই ক্যান্ডেল ফরোয়ার্ড টেস্ট করার সুবিধা।
- প্লে, পজ, স্টেপ ফরোয়ার্ড বাটন এবং স্পিড কন্ট্রোল (0.5s, 1s, 2s)।
- টাইমলাইন স্লাইডার স্ক্রাবার।

### ৯. ওয়াচলিস্ট ও অ্যাসেট কভারেজ
- ক্রিপ্টো: `BTC/USD`, `ETH/USD`, `SOL/USD`
- ভারতীয় বাজার (NSE): `NIFTY 50`, `RELIANCE`, `BANK NIFTY`
- ইউএস স্টক: `AAPL`, `TSLA`
- সার্চ ফিল্টার এবং ফেভারিট স্টার টগল।

### ১০. দ্বিভাষিক ইউজার ইন্টারফেস (Bengali & English)
- এক ক্লিকে সম্পূর্ণ ড্যাশবোর্ড বাংলা (🇧🇩) বা ইংরেজি (🇺🇸) ভাষায় রূপান্তর।

## ⚙️ সার্ভার-সাইড প্রোভাইডার আর্কিটেকচার (MarketDataProvider)
```typescript
export interface MarketDataProvider {
  id: string;
  name: string;
  getCandles(symbol: string, timeframe: Timeframe, count?: number): Promise<Candle[]>;
  getQuote(symbol: string): Promise<SymbolInfo | null>;
  subscribeQuotes(symbols: string[], onUpdate: (quote: SymbolInfo) => void): () => void;
}
```
- অ্যাডাপ্টারসমূহ:
  - `CryptoProviderAdapter` (`lib/marketDataProvider.ts`)
  - `IndianEquitiesAdapter` (`lib/marketDataProvider.ts`)
  - `CompositeMarketDataProvider`
- সার্ভার-সাইড API রাউট: `/api/market-data?symbol=BTCUSD&timeframe=1h`
